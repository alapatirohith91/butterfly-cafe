# Butterfly Cafe 🦋

Premium React + Vite cafe experience with a digital menu, gallery, responsive pages, cart and WhatsApp ordering UI.

## Stack

- React + Vite
- React Router
- Framer Motion
- Lucide React
- Responsive CSS

## Pages

Home · Menu · About · Gallery · Contact · Order

## Features

- Menu search and category filtering
- Add-to-cart and quantity controls
- WhatsApp order generation
- Responsive mobile navigation
- Gallery lightbox
- Review carousel
- Contact form demo
- Google Maps embed
- GitHub Pages deployment workflow

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Demo configuration

The project uses Unsplash photography and placeholder Hyderabad contact details. Replace the WhatsApp number, phone, email, Instagram link and exact map location before using it for a real cafe.
